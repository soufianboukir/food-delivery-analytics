

🧠 Goal

Deploy your ML model API (FastAPI + Docker) to AWS for free learning.

🥇 Best free AWS option (recommended)
✔ AWS EC2 Free Tier

This is the simplest and most realistic way to deploy your CD pipeline.

You get:

1 small VM (server)
750 hours/month free (enough for 24/7 learning)
🚀 Architecture you will use
GitHub Actions (CD)
        ↓
Docker image
        ↓
AWS EC2 (free VM)
        ↓
FastAPI model running
🪜 STEP 1 — Create AWS EC2 instance (free)
Go to AWS Console
Launch EC2 instance:
OS: Ubuntu 22.04
Type: t2.micro (FREE)
Allow ports:
22 (SSH)
8000 (FastAPI)
Download .pem key
🪜 STEP 2 — Install Docker on EC2

SSH into server:

ssh -i key.pem ubuntu@YOUR_EC2_IP

Install Docker:

sudo apt update
sudo apt install docker.io -y
sudo systemctl start docker
sudo usermod -aG docker ubuntu
🪜 STEP 3 — Test container manually
docker run -d -p 8000:8000 your-docker-image

Now your API is live:

http://EC2_PUBLIC_IP:8000/predict
🪜 STEP 4 — Modify GitHub CD (AWS version)

Instead of DockerHub deploy only, you SSH into EC2 and update container.

🔥 Updated CD job (AWS deployment)
- name: Deploy to AWS EC2
  uses: appleboy/ssh-action@v1.0.3
  with:
    host: ${{ secrets.AWS_HOST }}
    username: ubuntu
    key: ${{ secrets.AWS_SSH_KEY }}
    script: |

      docker pull your-dockerhub-user/delivery-model:latest

      docker stop model || true
      docker rm model || true

      docker run -d \
        -p 8000:8000 \
        --name model \
        your-dockerhub-user/delivery-model:latest
🔐 GitHub Secrets needed
AWS_HOST        → EC2 public IP
AWS_SSH_KEY     → your .pem private key
DOCKER_USERNAME
DOCKER_PASSWORD
🪜 STEP 5 — Open firewall

In AWS EC2 security group:

Allow:

Inbound rule:
TCP 8000 → 0.0.0.0/0
🧪 STEP 6 — Test API

Open browser:

http://YOUR_EC2_IP:8000/docs

FastAPI Swagger UI should appear.
